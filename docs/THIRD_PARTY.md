# Reuse and reference software

The solver, generated meshes, measured score tables, figures and new text are dedicated to the public domain under [CC0 1.0](../LICENSE). The legal code is the official Creative Commons text. Python dependencies retain their own licences and are installed separately.

No NCAR source, NCAR archive, NCAR binary, MPAS source, downloaded MPAS mesh or paper PDF is bundled.

## NCAR STSWM 2.0

The [Netlib distribution](https://www.netlib.org/chammp/) supplies `stswm.tgz`. Its README identifies the copyright as University Corporation for Atmospheric Research, 1992, all rights reserved. It limits the source to scientific research and educational purposes, says it is not public domain and asks that resulting publications acknowledge NCAR. It asks that substantial modifications be identified as a derivative of NCAR STSWM.

The download script checks SHA-256 `385b001d0b116f86026e8df9f8c27f7749ed0533231c8b42541b1b8e2af2d9f1`. Extraction preserves the upstream README and notices. Read those terms before use. These terms do not restrict this repository's independent solver, but they do restrict the fetched reference software. Do not include the fetched source in a CC0 redistribution.

The build script changes truncation and precision, replaces spectral netCDF output with a new grid writer, and adds file-based initial conditions for the jet and diagnostic cases. The published numerical comparisons acknowledge NCAR STSWM as the reference model. The score files contain our computed errors and diagnostics, not NCAR's source or reference-field archives. The patches and new grid writer are supplied to reproduce the research comparisons; they grant no rights over fetched NCAR code.

## Meshes and literature values

The comparison meshes are generated by `polarswe/trsk.py`. No third-party mesh files need downloading. TRSK is an implementation of published mathematics, rather than bundled MPAS code. The references are Thuburn et al. (2009), JCP 228, 8321-8335, and Ringler et al. (2010), JCP 229, 3065-3090.

Published comparison tables and digitised values from other papers are not redistributed. The paired TRSK comparison uses our own numerical runs. The original papers and their figures are not bundled.

The [Domain Translation paper](https://arxiv.org/abs/2511.11542) retains its own terms. This repository links it and uses its reported performance-model parameters. It does not redistribute the paper or its images.
